脆日炸雞｜店家 App
安裝後直接從手機或平板桌面接單，不用再找網址。
此裝置已經以 App 模式開啟。
店家 App 包含
1
即時接單查看新訂單、付款方式、內用桌號與備註。
2
製作與收款確認收款、開始製作、完成、取消與列印。
3
營業流水帳查看營業額、現金、LINE Pay、未收款與熱銷商品。
4
App 模式安裝後以獨立視窗開啟，桌面會出現「脆日店務」圖示。
iPhone / iPad 安裝方式
請使用 Safari 開啟本頁 → 點「分享」→ 選「加入主畫面」→ 點「加入」。
App 需要 HTTPS 正式網址才能安裝。訂單與流水帳仍由 Supabase 雲端同步；離線時只會保留 App 外殼，不會離線建立訂單。
